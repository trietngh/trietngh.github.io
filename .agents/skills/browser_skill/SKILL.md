# Browser Skill

## When to use this skill

When designing or making any changes in the web page, check the live development server to see the changes by following the step below:

## How to use it

1. Check if the development server is already running by using the following command: 
    ```bash
    ps aux | grep npm
    ```
2. If the development server is not running, use the `npm run dev` command to start the development server.
3. Open the live development server in your browser by navigating to `http://localhost:4321`.
4. Check the changes in the web page.
5. Repeat the steps above if you need to make any further changes.
