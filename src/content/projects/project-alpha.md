## Overview
This project was built to demonstrate modern web development practices. It utilizes a static site generator and utility-first CSS to deliver a highly performant and accessible user experience.

## Key Features
- **Blazing Fast:** Pre-rendered HTML for optimal load times.
- **Responsive Design:** Looks great on desktop and mobile devices.
- **Component-Driven:** Highly reusable UI components.

## Technical Details
The architecture relies heavily on Astro's island architecture, allowing for interactive components only where necessary, thus keeping the JavaScript bundle size to an absolute minimum.
